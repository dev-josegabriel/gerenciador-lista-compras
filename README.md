# Gerenciador de Lista de Compras

Aplicação de console em C# para gerenciar uma lista de compras, com exportação para arquivo `.txt`.

Projeto feito durante o curso de C# (Aula 19).

## Funcionalidades

- Adicionar item à lista
- Remover item da lista
- Exibir a lista atual
- Limpar a lista
- Exportar a lista para um arquivo `.txt`

## Como executar

Requer o [.NET SDK](https://dotnet.microsoft.com/download) instalado.

```bash
dotnet run
```

## Uso

Ao executar, um menu é exibido no console:

```
=== LISTA DE COMPRAS ===
1. Adicionar item
2. Remover item
3. Exibir lista
4. Limpar sua lista
5. Exportar lista em .txt
```

Basta digitar o número da opção desejada e seguir as instruções.
